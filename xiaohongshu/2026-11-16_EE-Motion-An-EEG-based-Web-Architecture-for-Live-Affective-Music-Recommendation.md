脑电感知＋情感适配器推荐架构

今天给大家带来一篇实时情感音乐推荐论文 EE-Motion：用浏览器连接脑电设备，通过情感适配器，让推荐随用户的生理信号变化而调整。

🔑 关键方法

1️⃣ 脑电信号采集：浏览器通过 Web Bluetooth 连接 Muse 2，采集脑电并进行滤波、功率谱估计和时间平滑。

2️⃣ 情感坐标映射：提取额叶 Alpha 不对称性和唤醒指数，映射到效价—唤醒度（V/A）二维平面，作为实时推荐的控制信号。

3️⃣ 候选歌曲排序：用户先选几首喜欢的歌，系统结合歌曲嵌入、实时 V/A 坐标和曲目情感标签，对候选歌曲重新打分。

💡 核心创新

1️⃣ 情感适配器：把实时情感条件接入不同推荐骨干，ACE 和 SASRec 等模型可以共用服务接口，不必为每个模型重写整套流程。

2️⃣ 匿名用户冷启动：对所选歌曲的嵌入取平均，得到临时用户表示，无需维护用户嵌入表，也无需在线重训练。

3️⃣ 输入与推荐解耦：除了脑电，也能手动拖动二维坐标来调整推荐；只要输入符合统一的 V/A 格式，下游排序无需修改。

📊 实验效果

✅ 本地测试中，ACE 和 SASRec 的单次推荐周期分别约为 90.3 ms 和 80.0 ms，低于 8 Hz 信号流对应的 125 ms 间隔。

✅ nDCG@10 上，实时版与离线版分别为：ACE 0.0231 vs 0.0236，SASRec 0.0164 vs 0.0148，差异均无统计显著性。

✅ 脑电指标是未经个体校准的情感代理信号，不等于经过验证的情绪识别，更不能用于临床判断。
