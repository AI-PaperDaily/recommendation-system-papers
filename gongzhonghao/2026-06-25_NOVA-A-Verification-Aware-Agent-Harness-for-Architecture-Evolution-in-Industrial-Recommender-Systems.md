## 腾讯广告推荐系统新突破：NOVA智能体架构演化系统，GMV提升2.02%，人工耗时缩短13倍

### 引言

在工业级推荐系统的世界里，模型架构的持续演化是驱动业务增长的核心引擎。从早期的LR、FM，到深度模型Wide&Deep、DeepFM，再到如今引入Transformer注意力机制的RankMixer和MixFormer，每一次架构革新都带来显著的性能提升。然而，将这些前沿的学术架构快速、可靠地落地到支撑数十亿用户的生产系统中，却是一个令所有技术团队头疼的难题。

传统的**自动机器学习（AutoML）** 方法主要聚焦于超参数调优，但对于需要跨模块拓扑变更的架构级升级显得力不从心。更致命的是，通用的**大语言模型（LLM）编码智能体**虽然能生成“可运行”的代码，却无法保证这些更改能保持推荐系统特有的**架构语义**——比如错误的掩码方向、参数组合不兼容等，这些“可运行但无效”的**静默失败**，是当前工业界的重大痛点。为此，腾讯的研究团队提出了**NOVA**——一个验证感知的、分层的智能体架构演化系统，它通过“架构梯度”搜索和级联验证机制，极大地提升了推荐系统架构演化的效率与成功率。

### 一、核心方法：从“搜索”到“智能演化”

NOVA的核心思想是将架构演化问题形式化为一个**反馈驱动的搜索过程**。它摒弃了传统的随机搜索或仅依赖运行信号的简单方法，引入了一种受**随机梯度下降（SGD）** 启发的结构化更新信号——**架构梯度**。

#### 1. 架构梯度：引导修改方向的“导航仪”

NOVA将每个候选架构表示为 `A_t = (G_t, φ_t, F_t)`，即模型图、结构超参数和特征配置。由于架构状态是离散且高度受约束的，传统的梯度下降法无法直接应用。研究者借鉴SGD的思想，提出了**架构梯度** `g_t`，它是一个结构化的非可微更新信息，旨在将过去的修改、验证结果和指标反馈转化为下一次迭代的行动指南。

这个架构梯度 `g_t` 的生成公式如下：

$$g_t = \mathrm{Grad}(e_{t-1}, V_t, \Delta J_t, H_t)$$

其中：
- `e_{t-1}` 是上一次的架构修改；
- `V_t` 是当前迭代的验证诊断信息；
- `ΔJ_t` 是离线评估指标（如AUC）的变化；
- `H_t` 是记录了所有成功和失败修改的**轨迹记忆**。

这个梯度不仅告诉智能体“哪里弱”（弱组件），还指明了“怎么改”（修改方向）和“别踩坑”（禁止方向），从而将架构演化从盲目的试错转变为有导向的智能探索。

#### 2. 级联验证：拦截“静默失败”的防火墙

这是NOVA最出彩的创新之一。研究者引入了**子任务级（L1-L4）** 和**执行模式（AutoRun/Copilot）** 的智能路由。更重要的是，它设计了一套**多阶段验证级联**，旨在训练的昂贵环节之前，就捕捉并剔除那些“可运行但无效”的候选方案。

![图2：NOVA的静默失败感知验证级联](https://arxiv.org/html/2606.27243v1/figure/4_4_4.png)

验证级联包含四个阶段：
- **结构语义门（L1）**：检查形状/数据类型兼容性、特征到令牌的映射、注意力方向、掩码语义等。这是拦截大多数“跑得起来但架构是错的”候选者的第一道防线。
- **本地执行门（L2）**：确保修改后的模型在单机上能够顺利跑起来。
- **离线内部循环（L3）**：通过真正的训练和AUC评估来验证模型效果。
- **在线外部循环（L4）**：在生产环境中验证真实的业务指标，如GMV和Bias。

被任何阶段拒绝的候选者，其失败模式都会被记录下来，作为“禁止方向”反馈给架构梯度，从而指导后续的搜索，避免重复犯错。

### 二、实验结果：彻底碾压传统方案

NOVA的效果在腾讯的工业广告系统中得到了验证。研究者在两个任务上进行了对比：**L2 ScaleUp（结构参数联合调优）** 和 **L3 Literature-to-Production（论文架构落地）**。

#### 1. 主实验结果：全面提升有效通过率

与人类专家循环、通用编码智能体OpenHands、ReAct智能体以及AutoML基线相比，NOVA的成绩堪称碾压式：

| 方法 | L2 ScaleUp EPR ↑ | L3 Lit-to-Prod EPR ↑ |
| :--- | :--- | :--- |
| **NOVA** | **54.5%** | **60.0%** |
| Human Expert Loop | 49.3% | 31.1% |
| OpenHands | 6.7% | 10.2% |
| ReActAgent-only | 12.5% | 7.1% |
| Optuna-TPE | 4.7% | – |

关键指标**有效通过率（EPR）** 衡量的是从生成候选到产生正向离线结果的成功率。在L3论文落地任务中，NOVA的EPR高达**60.0%**，比人类专家循环（31.1%）高一倍，更是碾压了OpenHands（10.2%）等基线。这证实了架构语义验证和梯度引导搜索的巨大价值。

#### 2. 消融实验：每个组件都不可或缺

研究者通过消融实验证实，NOVA的每个核心组件都至关重要。移除**论文解析**、**方案设计**、**质量控制**或**架构梯度反馈**，都会导致EPR大幅下降。这表明，仅靠“能跑”的代码远不足以实现有效的架构落地。

#### 3. 在线A/B测试：真金白银的商业价值

最令人信服的是在线A/B测试结果。NOVA在L3任务中选出的候选者被部署到生产系统后，带来了显著的业务提升：

| 目标 | GMV增长 | pCVR偏见降低 |
| :--- | :--- | :--- |
| task1 | **+1.25%** | **-58.8%** |
| task2 | **+1.70%** | **-66.7%** |
| task3 | **+2.02%** | **-37.3%** |

在提升GMV的同时，还大幅降低了预测偏差。这表明NOVA找到的不仅是能运行的代码，更是真正有效的架构方案。

### 三、展望：走向全漏斗、全生命周期的R&D自动化

NOVA的成功不仅是技术上的突破，更代表了推荐系统研发范式的一种进化方向。研究者规划了清晰的蓝图：NOVA将从当前的精排序阶段，向**检索、粗排、重排**等全漏斗扩展；从模型优化向包含**业务分析、特征工程、在线实验**等**全生命周期**的R&D自动化延伸。

它本质上是一套“让AI自己当架构师”的智能体系统。当AI能够理解论文意图、理解生产约束、自动验证并纠错时，研发的效率和生产潜力将被彻底释放。面对NOVA所带来的颠覆性改变，一个值得每个技术人思考的问题是：在AI辅助研发的浪潮中，推荐系统架构师的角色将如何演变？
