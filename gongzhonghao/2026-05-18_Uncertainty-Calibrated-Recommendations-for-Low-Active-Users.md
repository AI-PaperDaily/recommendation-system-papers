## 字节跳动&TikTok发布用户生命周期自适应推荐框架：HLT7提升0.057%的“不确定性”博弈论

### 一、引言

现代推荐系统正面临一个核心矛盾：如何为一个平台上的所有用户提供统一优质的服务体验？对于新登入或低活跃用户（LAU），系统因数据稀疏，预测极度脆弱，一次错误的推荐就可能导致用户永久流失。对于高活跃用户（HAU），系统则需主动探索兴趣边界，避免陷入信息茧房，以维持长期生态活力。然而，大多数主流推荐模型只能输出一个确定的分数，无法告知这个预测究竟有多可靠。面对这一挑战，来自Stanford大学与TikTok的研究团队联合提出了一套生产就绪、统一的不确定性感知推荐框架。该框架的核心洞察在于：**模型不确定性对低活跃用户是致命风险，而对高活跃用户则是探索机遇**。通过精准量化每个推荐请求的不确定性并配合差异化策略，该框架在TikTok的直播推荐上取得了显著效果：**低活跃用户留存时间（HLT7）提升0.058%，内容发现多样性（Show Tag/U）提升2.1%**。

### 二、核心方法

该框架的核心在于两套创新机制：**精准的不确定性量化**与**基于生命周期的差异化策略**。

#### 1. 双重不确定性量化引擎：从结果到风险

论文指出，传统推荐模型因训练数据的随机性和模型的局限性，其预测存在两类不确定性：
-  **模型不确定性（Epistemic）**：反映了模型对特定输入的“学习程度”。数据稀疏或分布外样本会导致该不确定性升高。
-  **数据不确定性（Aleatoric）**：用户行为本身固有的随机性（比如用户今天心情是否好），是模型无法消除的噪声。

框架为两种主流模型架构提供了互补的量化方案：
-  **对于点估计模型（如CTR预估模型）**：训练一个独立的“评论家网络”。它利用推荐模型内部的中间特征表示，精准预测每个**用户-物品**对的**期望预测误差（EPE）**。这相当于给模型配备了一个专门评估“犯错概率”的副驾驶。
-  **对于概率模型（如输出Beta分布的模型）**：采用**经验贝叶斯**方法，直接从数据中学习输入的依赖先验，从而将预测方差分解为数据不确定性和模型不确定性。其中，模型不确定性部分便是所需的风险信号。

这两个量化分数，一个来源于预测误差的直接学习，另一个来源于贝叶斯框架下的严谨分解，共同构成了全系统的基础风险感知。

#### 2. 风险信号的生命周期杠杆：降权与探索

获得不确定性分数后，框架引入了关键的校准环节，将原始分数转化为可操作的阈值，并依据用户生命周期执行完全相反的策略：

$$r^{\mathrm{final}}_{u,i}=r_{u,i}-D\cdot\mathbb{I}_{\mathrm{risky}}(u,i)$$

$$r^{\mathrm{final}}_{u,i}=r_{u,i}+\omega\cdot U_{\mathrm{HAU}}(x_{u,i})$$

以上两个公式极为精炼地概括了此框架的“一体两面”：
-  **低活跃用户的“风险厌恶”公式**：一旦某物品的不确定性超过阈值，其基础排名分 `$r_{u,i}$` 会被直接减去一个惩罚项 `$D$`。这种**降权（Deboosting）** 策略主动屏蔽了高风险、不可靠的推荐，有效避免了因误推可能导致用户流失的风险。
-  **高活跃用户的“风险寻求”公式**：恰恰相反，高不确定性 `$U_{\mathrm{HAU}}$` 被视为一种**探索奖励（Exploration Bonus）**。通过权重 `$\omega$` 将其加入基础分数，鼓励系统为用户推荐那些模型尚未充分了解的、但可能激发新兴趣的内容类别。这一策略本质上是**置信上限（UCB）** 原则在工业推荐场景的成功应用。

### 三、实验与效果验证

该框架在TikTok直播推荐平台的真实流量上进行了大规模离线与在线实验，验证了其工业级有效性。

#### 1. 离线量化：不确定性信号的真实性检验

在离线阶段，研究者从两个关键维度验证了其量化信号并非“盲猜”。
-  **与误差的相关性（图2(a)）**：如图2(a)所示，随着模型预测的不确定分位从低到高，线上的实际预测误差（MSE）也随之单调上升。这表明，系统给出的“高风险”信号，确实准确对应了更可能出现错误预测的场景。
-  **与常识的一致性（图2(b)与(c)）**：一个符合直觉的规律是，刚开播的直播间（年龄小）信息少，模型预测不确定性高；而随着直播进行，观众反馈增多，不确定性会逐步下降。论文的结果完美复现了这一假设，验证了量化方法的合理性与可解释性。

![[图2：(a) 真实线上MSE与预测不确定性的单调关系；(b)(c) 不确定性随直播时长而下降]](https://arxiv.org/html/2605.17788v1/figures/mse_trend_analysis.png)

#### 2. 线上A/B测试：显著的用户留存与多样性提升

线上实验的A/B测试结果为该框架的商业价值给出了最有力的证明。

| 产品指标 | 低活跃用户（LAU） | 高活跃用户（HAU） |
| :--- | :--- | :--- |
| **HLT7 (用户留存)** | **+0.0577%** | - |
| **VWR (有效观看时长比)** | **+0.512%** | - |
| **Show Tag/U (内容发现多样性)** | - | **+2.1%** |
| **Top1 Tag UV Ratio (类别平衡优化)** | - | **-0.42%** |

如上表所示，针对LAU，降权策略带来了**0.0577%的周留存增长**和**0.5%以上的有效观看时长比提升**，这表明用户确实花更多时间在更好的内容上。而对HAU，基于UCB的探索策略带来了**2.1%的类别覆盖率提升**，有效拓宽了用户的兴趣边界。对比使用ensemble、MC Dropout等方法，该统一框架在各项指标上均实现了大幅领先。

### 四、展望

该论文为解决推荐系统中的“风险-探索”权衡提供了一套极具操作性的工业级方案。它将看似抽象的不确定性量化概念，转化为具体可衡量的商业指标，实现了对不同阶段用户的精准赋能。未来，随着多模态与大语言模型的发展，如何将语义层面的不确定性也纳入考量，从而构建更智能、更可信的推荐生态，将是该领域一个值得深入探索的方向。
