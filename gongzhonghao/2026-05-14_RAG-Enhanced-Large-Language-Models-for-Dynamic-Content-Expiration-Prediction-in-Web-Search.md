## 百度搜索引入RAG增强大模型：动态内容过期预测准确率飙升，在线CTR提升12.8%

当用户在搜索引擎中输入一个查询时，最糟糕的体验莫过于得到一个读起来“新鲜”但内容已经“过期”的答案。例如，查询“今日油价”，得到的却是三个月前的一篇旧文；或者搜索“某地的最新政策”，结果却是一份早已废止的文件。这个问题在商业搜索引擎中尤为突出，因为传统方法往往陷入“一刀切”的困境：要么为所有近期内容无差别加分，要么简单粗暴地打压老文章。

针对这一长期存在的“语义有效期”难题，百度研究院（Tingyu Chen等）在最新发表的论文中，提出了一套基于大型语言模型（LLM）的创新框架。该框架将传统的、静态的时效性预测任务，重新定义为一种动态的、对查询意图敏感的“内容过期预测”问题。通过引入检索增强生成（RAG）范式，该方案在百度搜索中成功落地，并实现了令人瞩目的性能提升。

### 一、核心方法：让搜索引擎学会“理解”内容何时“失效”

传统搜索系统在处理时效性时，主要依赖一种称为**静态时间窗口**的规则。例如，系统设定一个30天的“新鲜期”，对在这个窗口内的文档统一施加一个“新鲜度加分”。这种方法计算简单，但问题在于，它无法区分不同信息的生命周期。一个两天前发布的“火灾已扑灭”的新闻，和一个三年前发布的“交通法规”，前者可能已经失效，后者依然精准有效。

为了解决这一根本矛盾，论文提出了一套三阶段、具备鲁棒性的动态过期预测框架。

#### 1. 时间信息提取模块：从噪音中捕捉关键时间线索

面对一篇长文档，直接交给模型去推理，很容易被无关信息干扰。因此，该框架首先引入一个**时间信息提取模块**。它并非简单地去看整篇文章，而是像一个 “时间侦探” ，先锁定文档中与查询相关的核心句子及其周围的时间锚点。

![图1：动态内容过期预测框架与传统方法的对比](https://arxiv.org/html/2605.13052v1/x1.png)

*图1清晰地展示了核心差异：对于“香港火灾”这类实时性新闻，传统方法会提升所有近期内容，导致失效信息（大“X”）胜出；而论文提出的新方法通过理解语义，正确地将已扑灭的火灾新闻标记为“过期”，同时保留了“交通法规”这类长期有效的权威内容。*

提取模块的工作分为两步。首先，它会解析查询，提取出查询中的关键词（如“火灾”）和时间实体（如“今天”），同时扫描文档，构建一个“时间→位置”的索引。其次，围绕这些锚点，系统会生成一系列**聚焦语义片段**，并计算每个片段与查询的相关性。

$$S_{rel}(c)=\mathbb{I}\_{K}(c\cap K\_{Q}\neq\emptyset)\cdot\left[\alpha\cdot Rel\_{K}(c,K\_{Q})+(1-\alpha)\cdot Rel\_{T}(c,T\_{Q})\right]$$

这个公式是筛选关键片段的核心。它首先通过一个指示函数 $\mathbb{I}\_{K}$ 来检查片段是否包含查询关键词。如果不包含，分数直接为0。如果包含，则综合考察**语义相似度** ($Rel\_K$)和**时间对齐** ($Rel\_T$)。通过超参数 $\alpha$ 来调节二者的平衡（论文中设为0.6）。这一步确保了输入给后续模型的，是问题相关且带有明确时间特征的浓缩信息。

### 二、推理与验证：用双重“保险”对抗大模型幻觉

#### 1. 结构化提示推理

经过筛选的、富含时间信息的片段被输入**大型语言模型**。研究者设计了一套精细的**结构化提示框架**，引导模型执行复杂的时序推理。框架的核心指令包括：
- **绝对时间锚定**：将模型的时间理解严格锚定在“当前搜索时间”上，避免概念混淆。
- **常识推理**：依赖模型的常识，理解不同信息的自然生命周期（例如，“选举结果”的有效期远短于“法律条文”）。
- **负向约束与思维链（CoT）**：明确要求模型避免提取无关的辅助日期，并强制模型一步步展示推理过程，而非直接给出结论。

![图2：基于LLM的查询感知动态内容过期预测框架概览](https://arxiv.org/html/2605.13052v1/x2.png)

*图2完整展示了整个预测框架的流程。从查询和文档输入，经过“时间信息提取”得到聚焦片段，再通过“结构化提示推理”与“时序一致性验证”模块，最终输出一个“有效期阈值”，并转化为可供线上使用的评分信号。*

#### 2. 时序一致性验证与幻觉抑制

这是论文最精彩的部分，专门应对大模型的“幻觉”问题。研究者设计了一个**双重验证架构**。首先，是 **对比式前向-后向思维链**。模型先通过正向推理（从文档到结论）得出一个“有效期”候选 $t_{init}$，然后立即反向验证：回到原文，去“挑错”，检查这个结论是否与文档中的证据逻辑自洽。这个自我博弈过程会计算一个一致性惩罚项，任何逻辑上的矛盾都会被量化并用于修正。

其次，是**权威加权证据融合**。当一个结论可能存在多个来源时，系统不会简单投票。它会结合每个证据来源的 **权威性** 和 **语义相关性** 来计算加权分数。最终，系统会选择获得最高证据支持的过期时间点作为最终输出：

$$t_{exp}^{*}=\arg\max_{t_{c}\in\mathcal{T}_{c}}\sum_{c\in S_{focus}}w_{c}\cdot\mathbb{I}\_{align}(t_{c},c)$$

这里，$w_{c}$ 代表每个证据片段的联合权重，它等于片段来源的权威性 $Auth(c)$ 和语义相关性 $S_{rel}(c)$ 的乘积。一个来自权威网站且和问题高度相关的证据片段，其话语权自然更大。这种方法有效避免了模型因为一些低质量或矛盾的信息而产生错误的过期判断。

最终，这个通过严谨推理得出的“有效期”阈值 $t_{exp}^{*}$，会被转化为一个简单的二值信号 $f_{exp}^{(i)}$。如果文档的发布时间晚于这个阈值，它就被视为“新鲜”；反之，则被标记为“过期”。这个轻量级的信号被无缝集成到百度的核心排序模型中，从而指导整个排序系统动态调整权重。

### 三、实验与落地：在线CTR提升12.8%，用户满意度双增长

为了验证框架的有效性，研究团队在百度搜索的真实流量上进行了大规模实验。

| 评估阶段 | 关键指标 | 相对提升(Δ%) |
| :--- | :--- | :--- |
| **离线评估** | 满意度得分 | +0.52% |
| | 正向导航率(1周内) | +7.36% |
| | 平均结果时效(前4名) | -2.44% |
| **在线A/B测试** | 高新鲜度查询平均时效(前4名) | **-12.81%** |
| | 用户满意消费 | +0.78% |
| | 点击率(前4名) | +0.41% |

*表格数据直观展示了论文方法的优越性。不仅增加了用户对新鲜内容的“正向反馈”（点击、满意消费），还显著缩短了搜索结果整体的“平均年龄”，尤其是在对时效要求极高的查询中，结果的新鲜度提升了近13%。*

在线A/B测试历时14天，覆盖了百度搜索全平台的5%流量。实验结果令人振奋：
- **用户消费行为显著改善**：用户**满意消费率（Satisfactory Consumption）** 提升了0.78%，**点击率（CTR）** 提升了0.41%。这表明，系统不仅让用户更愿意点击结果，更重要的是，用户在点击后获得了更好的、更符合预期的信息，证明了“动态过期”判断的有效性。
- **内容年龄全面降低**：对于高新鲜度需求的查询（如新闻、赛事），搜索结果前4名的中位数年龄降低了惊人的**12.81%**。这意味着用户几乎总是能看到最新的进展，而非过时的旧闻。

此外，在专业评委参与的盲测中，该方法在所有关键场景下都获得了压倒性的“好/差”比（Good to Bad Ratio），特别是在**长尾冷门**和**高时效性**查询上，优势更为明显，证明了其强大的通用性和在复杂场景下的鲁棒性。

### 四、展望：从“基于时间”到“基于语义”的认知升级

这项工作的核心价值在于**范式转变**。它将搜索引擎对时效性的评估，从对“物理时间戳”的被动依赖，提升为对“语义有效期”的主动推理。这意味着搜索引擎不再是简单地“看到”一篇两小时前的文档，而是真正“理解”了一个“选举结果”的时效性远低于“天气预报”。

这种具备语义理解能力的“内容过期预测”，不仅显著提升了搜索体验，也为未来搜索引擎处理动态、易变信息打开了新的大门。通过巧妙的“知识蒸馏”设计，将大模型复杂的推理能力转化为轻量级的在线信号，实现了工业级的高效部署。也许在不久的将来，用户将告别“搜索结果已失效”的困扰，真正体验到搜索引擎对信息生命周期的精准把握。
