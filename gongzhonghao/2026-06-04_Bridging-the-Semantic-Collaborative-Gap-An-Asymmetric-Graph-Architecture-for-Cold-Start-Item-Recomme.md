# Tubi 破解冷启动魔咒：非对称图架构Shallow-RHS实现全局TVT提升0.42%，冷内容曝光提速13%

## 引言

在视频流媒体平台的推荐系统中，**冷启动问题**始终是一个悬而未决的顽疾。当一部新电影或新剧集刚刚入库，没有任何用户的观看记录，推荐系统该如何精准地将其推送给可能感兴趣的用户？传统的协同过滤方法依赖用户交互数据，对于零交互的新内容束手无策；而纯内容推荐虽然可以处理新内容，却往往只捕捉语义相似性，忽略了真实的用户偏好行为。

来自Tubi（美国领先的广告支持型流媒体平台，服务数亿用户）的研究团队，在Kumo AI的图神经网络平台支持下，提出了一种名为**Shallow-RHS**的非对称图架构，将冷启动推荐转化为归纳式图补全问题。该方法在Tubi生产环境的大规模在线A/B测试中，实现了全局总观看时间（TVT）提升0.42%，冷内容推广速度提升13%，设备冷启动参与度提升0.43%。本文将为深度解析这一创新方法的核心技术原理与实验效果。

## 一、核心方法：非对称双塔架构与归纳式图补全

### 1.1 问题形式化：冷启动即图结构缺失

研究团队将冷启动推荐问题形式化为一个**时序二部图上的链路预测任务**。该图由设备节点（用户身份）和内容节点（节目/标题）组成，边代表带时间戳的观看事件。关键区别在于，冷内容节点在图中没有任何观测到的边，因此传统的图神经网络无法为其生成有意义的节点表征。

论文的形式化定义如下：

$$ \mathcal{C}_{cold} = \{c \mid (d,c,\tau,\cdot) \notin \mathcal{E}, \forall d, \tau\} $$

这表示冷内容节点集合中，所有设备与内容之间在任何时间点都不存在观看事件边。面对这种极端图结构缺失，研究者目标直接学习两个嵌入函数：

$$ \mathbf{z}_{d}(t)=f_{\theta_{d}}(\mathbf{x}_{d},\mathcal{N}^{<t}(d)) \qquad \mathbf{z}_{c}=f_{\theta_{c}}(\mathbf{x}_{c}) $$

其中设备嵌入依赖历史观看子图，而内容嵌入被严格约束为仅依赖内在特征，这一非对称约束是整套方法的核心。

### 1.2 Shallow-RHS：左深右浅的非对称架构

**Shallow-RHS**架构的名称揭示了其设计精髓：右侧（RHS，内容侧）相对于图结构是“浅层”的。

![图2：Shallow-RHS架构图](https://arxiv.org/html/2606.06225v1/x2.png)

**左侧（LHS）设备塔**是一个深度图编码器。它首先通过HeteroTF风格的表格编码器处理设备特征（国家、平台、设备类型等），然后利用时序消息传递聚合历史观看事件的信息。每条历史边携带内容嵌入、总观看时间和时间衰减权重，通过多个聚合层更新设备表征。

**右侧（RHS）内容塔**则故意保持浅层——仅使用HeteroTF编码器处理内容的内在特征（元数据、类型、语言、发布时间、LLM生成的语义嵌入等）。这一设计**刻意禁止**内容塔使用任何ID嵌入、内容侧子图、邻居聚合或交互派生的表征。

这种设计背后的逻辑是：通过强制内容编码器仅从特征层面解释设备-内容交互行为，迫使模型学习到一个从语义特征到协同过滤嵌入空间的映射函数。训练完成后，这个函数可以无缝应用于零交互的新内容，实现“归纳式图补全”。

### 1.3 隐式图补全：通过替身邻居实现冷内容检索

训练完成后，研究团队使用学习到的内容编码器为所有内容（包括温内容和冷内容）生成嵌入向量：

$$ \mathbf{z}_{c}=f_{\theta_{c}}(\mathbf{x}_{c}) $$

然后，在温内容嵌入集合上构建近似最近邻（ANN）索引。对每个冷内容节点，检索其最相似的M个温内容作为**替身邻居**：

$$ \mathcal{S}_{M}(c)=\operatorname{TopM}_{w\in\mathcal{C}_{warm}}\cos(\mathbf{z}_{c},\mathbf{z}_{w}) $$

这些替身邻居作为服务时的行为代理——冷内容可以继承附近温内容在协同过滤空间中的证据，用于推广、检索或校准决策。这种方法隐式地完成了冷内容周围的图结构补全，而无需修改观测到的交互图。

## 二、设备冷启动：人口统计学先验

Shallow-RHS还将同样的表征补全原理扩展到设备冷启动场景。对于新激活的设备，其没有历史观看数据，无法通过左侧设备塔生成有意义的嵌入。

![图3：设备冷启动流程](https://arxiv.org/html/2606.06225v1/x3.png)

研究团队将温设备聚类为约K_D个人口统计学群组，基于可用设备和账户属性。对每个群组，计算该群组中温设备学习到的嵌入的平均值。对于新设备，根据其人口统计学特征推断所属群组，使用群组嵌入作为其初始设备表征。这使得即使是全新设备也能立即通过ANN检索获取个性化内容推荐。

## 三、实验效果：渐进式特征增强的实证验证

### 3.1 实验设置与数据

所有实验在Tubi生产推荐系统中以随机化在线A/B测试进行。实验构建了包含数亿设备节点、数十万内容节点和数十亿时序边的二部图。关键训练数据来自一年的观看历史日志。

![图4：相似度分布对比](https://arxiv.org/html/2606.06225v1/scoredist.png)

上图清晰展示了不同嵌入策略下相似度分布的差异。传统的协同过滤（CF）嵌入中，冷内容因缺乏交互历史而集中在低相似度区域；纯语义嵌入分布较集中但缺乏行为信号；而Shallow-RHS产生的嵌入显著向右偏移，表明其成功地将冷内容对齐到协同过滤感知的嵌入空间。

### 3.2 四阶段渐进式实验

研究团队通过四个阶段的在线实验，逐步验证了该方法各组件的作用：

| 阶段 | 模型 | GNN架构 | 语义嵌入 | 校准优化 | 特征增强 | 替身邻居 | TVT提升 |
|------|------|----------|----------|----------|----------|----------|---------|
| V1 | Shallow-RHS | ✓ | ✓ | × | × | × | +0.10% |
| V2 | Shallow-RHS | ✓ | ✓ | ✓ | × | × | +0.16% |
| V3 | Shallow-RHS | ✓ | ✓ | ✓ | ✓ | × | +0.42% |
| V4 | Shallow-RHS | ✓ | ✓ | ✓ | ✓ | ✓ | +0.17% |

**Phase 1**：用Shallow-RHS嵌入替换纯语义嵌入，获得+0.10%的全局TVT提升，冷内容推广速度提升13%。

**Phase 2**：改进输入特征覆盖率（添加预算、票房等信号）和校准决策逻辑，TVT提升至+0.16%。

**Phase 3**：进一步扩大特征覆盖率（提升约10%），实现近完整覆盖，TVT提升达到**+0.42%**，为所有阶段中的最大增幅。

**Phase 4**：引入目标受众和人口统计学描述符，并利用预训练LLM嵌入作为少数长尾内容的替代表征，获得+0.17%的额外提升。

### 3.3 设备冷启动效果

在新激活设备的A/B测试中，设备冷启动检索策略显著改善了多项参与度指标：
- 合格观看天数提升 **+0.29%**
- 每日封顶总观看时间提升 **+0.39%**
- 首页5分钟转化率提升 **+0.43%**

这些结果表明，从人口统计学先验重建缺失的设备表征，能有效改善第一次触达的推荐质量，与内容侧的冷启动改进形成互补。

## 四、展望

Tubi提出的Shallow-RHS架构为流媒体平台的冷启动问题提供了一种可落地的生产级解决方案。其核心洞见——将冷启动视为图结构缺失问题，并通过非对称架构将协同过滤信号转移至内容特征编码器中——具有广泛的应用价值。

该方法已在Tubi生产系统中部署并持续产生收益，相关技术也在Kumo GNN平台上实现。对于其他面临冷启动挑战的推荐系统（电商、社交平台、新闻推荐等），这种将语义特征与协同过滤行为对齐的思路提供了清晰的技术路径。

在实际落地中，研究者发现**内容侧特征覆盖率**是制约冷启动效果的关键瓶颈，这一发现对任何想要采用类似方法的团队都是一个重要提示：在追求高级模型架构之前，先确保输入特征的质量和完整性。
