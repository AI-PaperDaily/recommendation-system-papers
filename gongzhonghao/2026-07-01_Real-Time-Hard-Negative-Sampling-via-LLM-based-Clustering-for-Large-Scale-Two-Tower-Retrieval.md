## Meta 最新突破：实时聚类硬负采样让双塔召回模型 CTR 飙升 53%

在工业级推荐系统领域，双塔模型凭借高效的服务性能，成为召回阶段的标配。然而，其训练过程长期受困于“负样本太简单”和“流行度偏差”两大顽疾：传统的 Batch 内负采样受限于批次大小，而随机负采样又因难度不足，难以提供有效的梯度信号。

为了解决这一痛点，Meta 的研究团队提出了一种名为 **Cluster GOOBS（Cluster-based Global Out-of-Batch Sampling）** 的实时负采样框架。该框架巧妙结合大语言模型 (LLM) 进行语义聚类与高效内存池技术，在公共数据集上实现了 **+55.6%** 的 HR@50 提升，并在工业级线上 A/B 测试中斩获 **+53%** 的 CTR 提升，同时将 Top-100 热门物品的曝光占比从 50% 显著降至 32%。

### 一、核心挑战：当“简单”的负样本成为瓶颈

对于双塔召回模型，其本质是一个极多分类问题（Extreme Classification）。模型的目标是从海量候选池中精准定位与用户最相关的 K 个物品。标准的训练方式通常采用混合负采样（Mixed Negative Sampling），即混合同批次内其他样本与批次外的随机样本作为负样本。然而，这两种策略都存在明显缺陷：

-   **In-batch 负采样**：负样本与正样本同处一个小批次，不仅类别有限，而且极易产生“假阴性”（即真正的正样本被当作了负样本），导致模型学习出现偏差。
-   **Out-of-Batch 负采样**：从全量池中随机选取的负样本，对于模型而言大多是“一眼假”的易区分样本。这些样本产生的梯度极小，无法有效驱动模型去学习物品间的细微差异。

研究团队指出，理想的负样本应当是 **Hard Negative（硬负样本）**，即那些与正样本高度相似、但确实不满足用户需求的物品。这种样本能迫使模型学习到更精细的判别边界。

### 二、创新方法论：LLM 聚类驱动的硬负采样

为了高效、动态地生成硬负样本，论文提出了一个包含两个核心的解决方案：**LLM 聚类生成** 与 **GOOBS 实时采样框架**。

#### 1. 基于 LLM 的语义聚类（LLM-based Clustering）

传统的聚类方式（如按物品类别或主题）粒度粗糙，难以捕捉物品间的语义相似性。研究者另辟蹊径，利用一个经过微调的多模态大语言模型 (LLM) 来生成物品表征，并据此进行聚类。

这一过程包括三个关键步骤：

-   **预训练**：利用预训练 LLM 强大的语言理解能力。
-   **多模态编码**：对文本、图片、视频等不同模态信息进行统一的向量编码。
-   **微调**：针对具体下游任务进行微调，使生成的聚类更具区分度。

通过这种方式，相似语义的物品（例如不同品牌的“跑鞋”）会被聚合到同一个簇中。从同一簇中采样出的负样本，天然就具备了“高相似度”和“高迷惑性”的硬负特征。

#### 2. GOOBS：实时、高效的采样引擎

传统的硬负采样（如 ANCE）需要维护一个全局的最近邻索引，在大规模数据下计算和存储成本极高，难以在工业界落地。Cluster GOOBS 则通过一个巧妙的“物品池”设计，实现了低延迟的实时采样。

![图1：LLM-based cluster generation](https://arxiv.org/html/2607.00448v1/x1.png)

-   **GOOBS 框架的工作流**：如上图所示，训练数据中的物品特征会被实时存入一个结构化的内存池中。该内存池按“簇”进行分片，每个簇包含多个槽位（Slot）。训练批次中的正样本会驱动两个关键引擎：
    -   **更新引擎**：通过哈希函数，将当前批次中每个物品的 ID 和其所属的簇 ID 映射到内存池的对应槽位，完成特征的实时更新。
    -   **采样引擎**：根据当前批次中正样本的簇 ID，直接从对应的簇分片中随机选取一个已有物品，作为该正样本的硬负样本。

#### 3. 理论依据

论文从对比学习（Contrastive Learning）的理论角度解释了为什么簇内负采样更有效。对于一个标准的两塔模型，其损失函数可以简化为交叉熵损失。在批次训练中，对于给定的用户 $x_i$ 和正样本 $y_i$，损失函数为：

$$
\mathcal{L}(\{x_i,y_i,r_i\},\{x_i,y_{ik}^{-n},0\}_{k=1}^{K})=-r_i\cdot\log\left(\frac{e^{s(x_i,y_i|\theta)}}{\sum_{j\in\{y_i,\{y_{i1}^{-n}\}_{k=1}^{K}\}}e^{s(x_i,y_j|\theta)}}\right)
$$

其中 $s(x_i,y_j|\theta)$ 是用户和物品的点积相似度。当负样本 $y_j^-$ 与正样本相似时，其相似度得分 $s$ 会保持在较高水平，从而迫使模型在该例上产生更大的梯度，去学习如何精准区分相似的簇内物品，而非依赖容易的跨簇区分。

### 三、实验效果：公共数据与工业部署的双重验证

研究团队在 MovieLens-1M 和 Amazon Reviews 等多个公共数据集上，将 Cluster GOOBS 与 In-batch、DNS、CBNS、ANCE 等主流方法进行了对比。

**表 1: 公共数据集上的召回率对比**

| 数据集 | 指标 | Baseline (In-batch) | DNS | CBNS | ANCE | **Cluster GOOBS** |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| Amazon-Electronics | HR@50 | .0084 | .0090 | .0099 | .0108 | **.0131 (+55.6%)** |
| Amazon-Home | HR@50 | .0050 | .0054 | .0061 | .0065 | **.0074 (+47.3%)** |
| MovieLens-1M | HR@50 | .2253 | .2298 | .2331 | .2380 | **.2415 (+7.2%)** |

从表中可以清晰看到，在稀疏的大型数据集（如 Amazon）上，Cluster GOOBS 的相对提升非常显著，分别达到了 55.6% 和 47.3%，远超其他基于几何距离的硬负采样方法。

更重要的是在工业部署中的表现。Meta 将该方法应用于其大规模推荐系统，并进行了线上 A/B 测试。结果显示，关键业务指标 **CTR 提升了 53%**，而训练 QPS 仅下降了 1.4%，几乎可以忽略不计。更令人惊喜的是，该框架成功地缓解了推荐系统中的流行度偏差问题。在应用 Cluster GOOBS 后，Top-100 最热门物品的曝光占比从 50% 锐减到 32%，更多被忽视的“长尾”内容获得了展示机会。

### 四、展望

Cluster GOOBS 的提出，为双塔模型的训练范式提供了一个极具实用价值的解决方案。它巧妙地利用了 LLM 的语义理解和内存池的高效性，将“获取难负样本”这一昂贵操作变得轻量、实时且可扩展。这不仅是 Meta 在自身推荐系统上的一次重大效率提升，也为整个工业界在解决采样偏差、提升模型上限方面，提供了全新的思路。

未来，如何将用户的实时 Query 信息也引入到负采样过程中，以生成更加个性化的硬负样本，可能是一个值得探索的方向。
