Structuring and Tokenizing Distributed User Interest Context for Generative Recommendation

📅 2026-06-20

Meta联手UIUC提出G2Rec：工业级生成式推荐新框架，在线指标飙升0.19%的秘诀

在工业级推荐系统中，生成式推荐（Generative Recommendation）正成为预测用户下一互动行为的主流范式。然而，现有方法在同时建模用户行为图谱的全局结构与物品的语义信息时，常面临扩展性瓶颈：图序列化方法导致长序列计算代价高昂，而图神经网络（GNN）仅能感知局部子图。同时，语义分词方法缺乏显式监督信号，可能导致不准确的表示。

针对这些痛点，伊利诺伊大学厄巴纳-香槟分校与Meta的研究者联合提出了 G2Rec——一种稀疏协同图模式（Sparse Co-Engagement Graph Schema）驱动的生成式推荐框架。该论文通过在多个产品表面的在线部署与公开数据集实验，验证了其在准确表征用户兴趣原型上的卓越性能。

一、核心方法：两项关键技术突破

1. 稀疏化物品共现图：从$O(M^2)$到$O(M \log M)$

传统物品-物品共现图存在二次方复杂度（$O(M^2)$），在大规模场景下难以处理。论文提出一种基于图拉普拉斯近似保留的稀疏化策略：为每个用户随机采样$m$个共现对，使总边数降至$O(M \log M)$。理论保证如下：

$$m := \Big\lceil 2N\Big(\frac{1}{3\epsilon}+\frac{1}{\epsilon^2}\Big)\log\frac{2|\mathcal{I}|}{\delta}\Big\rceil,$$ $$(1-\epsilon)L_{\mathcal{E}^*} \preceq L_{\mathcal{E}} \preceq (1+\epsilon)L_{\mathcal{E}^*}.$$

该稀疏图保留了原始图的结构信息，为后续聚类提供了高效基础。

2. 可微分软聚类：从硬分配到模糊隶属度

传统图聚类方法（如Louvain、Leiden）强制节点归属单一集群，无法表征物品同时属于多个兴趣原型的特性（例如“手机”可能关联“科技”与“生活”）。论文提出可微分的软聚类目标函数，最大化期望模块度：

$$Q_{\text{soft}}(P) := \frac{1}{|\mathcal{E}|}\sum_{(i,j)\in\mathcal{E}}p_i^\top p_j - \gamma\frac{\|P^\top k\|_2^2}{|\mathcal{E}|^2}.$$

其中$p_i$表示物品$i$的软隶属度分布。该函数可通过GPU端到端优化，当隶属度矩阵$P$每行仅$\rho$个非零元素时，计算复杂度为$O(\rho M \log M)$。

3. 兴趣原型分词与序列重构

基于软聚类结果，每个物品的兴趣原型嵌入（$v_a$）被定义为属于该原型的物品嵌入的加权平均。随后，兴趣特征令牌（$y_i$）由原型嵌入加权组合得到：

$$y_i := \sum_{a=1}^C p_{i,a} v_a.$$

最终的用户交互序列被重构为交替物品嵌入与兴趣令牌的形式：$[\langle BOS \rangle, x_{i_1}, y_{i_1}, \dots, x_{i_N}, y_{i_N}]$，使生成式模型能同时学习物品语义转移和兴趣模式转移。

二、实验验证：全面超越现有方法

离线测试：密集且全面的性能优势

在Beauty、Sports、Toys、Yelp四个公开数据集上，G2Rec与6种强基线方法（包括GRU4Rec、SASRec、BERT4Rec、LightGCN等）进行对比。在所有数据集的所有指标上，G2Rec均取得了最优结果。

以Sports数据集为例，G2Rec的NDCG@5达到0.2869，较最佳基线方法高出14.9%。在Beauty数据集上，Recall@1达到0.2067，远超第二名GRU4Rec的0.1870。

在线A/B测试：产品表面上的真实收益

在Meta多个产品表面的在线部署中，G2Rec带来了0.03%的会话内提升，并在用户参与度指标（如总停留时间、点赞、分享）上实现0.06%至0.19%的持续增长。这些结果证明其在实际工业场景中能有效提升用户体验。

效率与消融研究：软聚类与兴趣令牌不可或缺

效率分析显示，G2Rec引入的兴趣令牌仅带来0.0027秒/批次的推理延迟增加，几乎可以忽略不计。而消融实验进一步证实：

方法 模块度（Beauty） 模块度（Sports） 模块度（Toys） 模块度（Yelp）
硬聚类（Leiden） 0.419 0.365 0.437 0.691
软聚类（G2Rec） 0.499 0.452 0.550 0.757

当兴趣令牌损失权重λ=0时，MRR显著下降，凸显其在指导模型学习兴趣转移模式中的关键作用。

三、展望：从生成式推荐到兴趣理解

G2Rec通过构建协同图与软聚类，为生成式推荐系统提供了一种可扩展、高精度的兴趣建模方案。未来工作可探索以下方向：
- 融合更多数据源（如文本描述、图像特征）以增强兴趣原型的语义丰富度；
- 研究动态图更新机制，使模型能捕捉用户兴趣的实时变化。

当推荐系统开始真正“理解”用户兴趣的模式，而非仅基于历史交互做统计预测，个性化服务的边界将被重新定义。你认为，这种基于图结构的兴趣原型是否会在下一代推荐系统中成为标配？欢迎在评论区分享见解。
