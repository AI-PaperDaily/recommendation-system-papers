Structuring and Tokenizing Distributed User Interest Context for Generative Recommendation

📅 2026-06-22

Meta 发布全新推荐框架 G2Rec：兴趣建模效率提升 14.9%，0.19% 线上指标提升的背后

在推荐系统的世界里，如何更精准地捕捉用户的真实兴趣，始终是业界与学界共同追逐的目标。传统方法要么依赖用户的显式行为序列，要么构建复杂的图神经网络，但总在“可扩展性”与“语义理解深度”之间顾此失彼。一篇来自伊利诺伊大学厄巴纳-香槟分校与 Meta 的研究，提出了一种名为 G2Rec 的全新框架，通过软图聚类与分布式兴趣分词，为工业级的生成式推荐系统找到了一个平衡点。论文不仅理论扎实，更在 Meta 多个产品面部署并取得了 0.06% 到 0.19% 的用户参与度全面提升。

一、核心方法：从稀疏共现图到兴趣配置

G2Rec 的核心思路可以概括为三个关键步骤：构建稀疏化的物品共现图、提取软聚类下的兴趣原型，以及将这些原型转化为序列的“兴趣令牌”。

1.1 稀疏化的共现图：用 $O(M \log M)$ 的边捕捉全局结构

传统方法构建物品关系图时，若考虑所有用户的交互对，边的数量是 $O(M^2)$ 量级（M 为总交互数），在大规模工业场景下完全不可行。G2Rec 的解决方案是提出一种 稀疏化的物品-物品共现图。对于每个用户，论文只从其交互历史中随机采样固定数量的共现对，从而将总边数降低到 $O(M \log M)$。

这项操作在理论上是有保证的。研究表明，这种采样方式能够近似保持原始图的拉普拉斯矩阵结构。

$$(1-\epsilon)L_{\mathcal{E}^*} \preceq L_{\mathcal{E}} \preceq (1+\epsilon)L_{\mathcal{E}^*}$$

这张图是理解用户行为模式的基础。它不依赖物品自身的特征相似性（如手机与手机壳），而是捕捉“哪些物品经常被同一用户一起互动”的行为模式。

1.2 软聚类：用可微的模块度发现分布式兴趣

有了图结构，接下来需要从中提炼出“兴趣原型”。不同于 Louvain 等将每个节点唯一分配至一个簇的硬聚类算法，G2Rec 采用了 软聚类。因为它认识到，一个物品（比如一段“牛油果吐司”视频）可能同时归属于“健康饮食”和“早餐习惯”等多个兴趣原型。

为此，研究者提出了一种基于 可微模块度 的目标函数，它可以端到端优化，且支持 GPU 加速。

$$Q_{\text{soft}}(P) = \bigg(\frac{1}{|\mathcal{E}|}\sum_{(i,j) \in \mathcal{E}} p_i^\top p_j\bigg) - \gamma \frac{\|P^\top k\|_2^2}{|\mathcal{E}|^2}$$

在这个目标中，$p_i$ 是一个概率向量，表示物品 i 属于各个兴趣原型的程度。最大化 $Q_{\text{soft}}$，等价于让那些在图中频繁共现的物品（即 $p_i^\top p_j$ 大）被赋予相似的软聚类分布，同时抑制随机共现带来的噪声。由于每个物品的 $p_i$ 只有少数几个非零项（稀疏性 $\rho$），整个计算复杂度可以控制在 $O(\rho M \log M)$。

1.3 兴趣配置分词：让推荐模型看到“兴趣迁移”

得到每个物品的软聚类分布后，G2Rec 将其转化为序列中的新型令牌。对于每个兴趣原型 a，计算其原型嵌入：

$$v_a := \frac{\sum_{i \in \mathcal{I}} p_{i,a} x_i}{\sum_{i \in \mathcal{I}} p_{i,a}}$$

随后，每个物品的 兴趣配置文件令牌 是其所属原型的加权平均：

$$y_i := \sum_{a=1}^{C} p_{i,a} v_a$$

最终，用户的交互序列被改造为：[BOS, x_i1, y_i1, x_i2, y_i2, ...]。模型不仅需要预测下一个物品（$\mathcal{L}_{\text{item}}$），还需要预测当前交互对应的兴趣配置文件（$\mathcal{L}_{\text{profile}}$）。这种双任务训练机制，让生成式推荐器不仅能学习到用户“点了什么”，还能学习到用户“为什么点”。

二、实验：离线与在线双轮验证

G2Rec 的验证分为离线大规模对比和线上 A/B 测试。

离线实验：

在 Beauty、Sports、Toys、Yelp 四个公开数据集上，G2Rec 全面超越了包括 SASRec、BERT4Rec、LightGCN 在内的六个强基线方法。

数据集 指标 最佳基线 G2Rec (Ours)
Sports NDCG@5 0.2497 (GRU4Rec) 0.2869
Beauty MRR 0.2852 (GRU4Rec) 0.3034
Toys Recall@10 0.4663 0.4691
平均排名 - 2.46 (GRU4Rec) 1.04 (第一名)

软聚类带来的收益显著。在模块度指标上，G2Rec 的软聚类相比硬聚类（Leiden 算法）提升了超过 23%（Sports 数据集从 0.365 提升至 0.452）。

在线实验：

在 Meta 多个产品面的大规模在线 A/B 测试中，G2Rec 带来了 0.06% 到 0.19% 的多项用户参与度提升，包括总使用时长、点赞数、分享数等，且会议内（in-session）提升超过 0.03%。

效率方面， 在 13B 参数的 Llama 2 模型上，引入兴趣令牌后，单批次训练时间仅增加 0.043 秒，推理时间增加 0.0027 秒，几乎可以忽略不计。

三、展望

G2Rec 的价值在于它提供了一种无需用户真实兴趣标签，就能为推荐系统注入“可解释的、可迁移的”兴趣知识的方法。这套“图结构聚类 + 令牌化”的范式，或许不仅适用于推荐系统。在 AI Agent 的行为建模、用户画像构建等领域，通过稀疏化的交互图来提取细粒度、分布式的“行为原型”，同样大有可为。

当推荐模型开始理解兴趣的流动，而非仅仅预测下一次点击，我们手中的信息流才真正开始变得有温度。
