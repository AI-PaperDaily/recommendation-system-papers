Seeing and Reflecting: Multimodal Memory-Enhanced Agent Collaboration for Recommendation

📅 2026-07-10

多模态记忆增强智能体协作框架MMEACR：推荐系统性能提升45%的背后技术

一、引言

在当今的推荐系统领域，基于大语言模型（LLM）的智能体推荐系统正逐渐成为研究热点。这些系统通过自然语言推理来模拟用户偏好，在可解释性和灵活性方面展现出显著优势。然而，现有方法普遍面临两个核心痛点：一是过度依赖纯文本输入，忽视了产品图片中的视觉线索；二是记忆更新机制过于粗糙，容易引入语义噪声，导致用户偏好漂移。

针对这些问题，来自清华大学、中国科学技术大学、北京大学、新南威尔士大学、麦考瑞大学和CSIRO's Data61的研究团队提出了一项创新解决方案——MMEACR（多模态记忆增强智能体协作推荐框架）。该框架在Fashion数据集上实现了N@1指标45.45%的提升，在Cell_Phones数据集上N@5提升了21.26%，展现出强大的性能优势。

二、双轨记忆架构：融合推理与匹配

MMEACR的核心创新在于其独特的双轨记忆架构，这一设计将可解释的智能体推理与细粒度的多模态匹配分离，从而克服了传统方法的核心局限。

传统的智能体推荐方法（图1a）完全依赖文本记忆，通过不断积累交互历史来更新用户和物品描述。相比之下，MMEACR（图1b）引入了一个并行的多模态嵌入记忆通道，使得视觉信息和原始交互叙事能够直接用于密集匹配。

推理轨道：属性引导的记忆进化

在推理轨道中，用户记忆智能体和物品记忆智能体协同工作，维护持续演化的语义记忆。当用户与物品进行交互时，系统会构建一个三元组$(u, i^+, i^-)$，其中$i^+$是正样本，$i^-$是负样本。LLM智能体基于当前的记忆状态做出选择，并生成推理依据。

为了防止自由形式推理带来的语义噪声，MMEACR引入了一个属性引导的强化与反思机制。系统从预定义的语义属性空间$\mathcal{A}=\{a_1,\dots,a_K\}$中提取与偏好相关的属性特征，并用其指导记忆的更新方向：

$$\mathbf{z}^{(t)}=f_{\mathrm{attr}}\left(M_{u}^{(t)},T_{i^{+}},T_{i^{-}},r^{(t)},\mathcal{A}\right)$$

其中$\mathbf{z}^{(t)}\in\mathbb{R}^{K}$编码了解释正负样本偏好差异的关键属性。这一设计使得智能体在强化正确偏好信号的同时，能够反思并修正误导性的记忆描述，有效减少了语义噪声和偏好漂移。

匹配轨道：多模态嵌入记忆

结构化记忆更新可能会过滤掉细粒度的视觉或文本细节。为此，MMEACR维护了一个多模态嵌入记忆，直接保存原始交互叙事和物品图像。使用预训练的多模态嵌入模型，系统将用户和物品映射到密集表示空间：

$$s_{\mathrm{emb}}(u,i)=\frac{\mathbf{e}_{u}^{\top}\mathbf{e}_{i}}{\|\mathbf{e}_{u}\|\|\mathbf{e}_{i}\|}$$

这种基于余弦相似度的密集匹配，能够捕捉到结构化记忆难以表达的跨模态语义信号，例如产品图像的色彩、纹理和风格等视觉特征。

三、混合排序：加权倒数排序融合

如何将推理轨道的可解释判断与匹配轨道的细粒度相似度有效结合？MMEACR采用了加权倒数排序融合（RRF）策略，为每个候选物品计算融合分数：

$$S_{\mathrm{RRF}}(i)=w_{\mathrm{des}}S_{\mathrm{des}}(i)+w_{\mathrm{emb}}S_{\mathrm{emb}}(i)$$

其中$S_{\mathrm{des}}(i)=\frac{1}{k_{\mathrm{des}}+\mathrm{rank}_{\pi_{\mathrm{des}}}(i)}$来自推理轨道，$S_{\mathrm{emb}}(i)=\frac{1}{k_{\mathrm{emb}}+\mathrm{rank}_{\pi_{\mathrm{emb}}}(i)}$来自匹配轨道。通过调整权重$w_{\mathrm{des}}$和$w_{\mathrm{emb}}$，系统能够在不同领域实现最优的排序性能。

四、实验验证：全面超越现有方法

研究者在Amazon评论数据集上的三个子集（CDs、Cell_Phones、Fashion）进行了实验，采用留一法进行评测。每个测试案例包含1个正样本和9个随机负样本。

如表所示，MMEACR-RRF在所有数据集上均取得了最佳或次优性能。特别是在视觉密集的Fashion领域，N@1从0.2200提升至0.3200，提升了45.45%；MRR从0.3987提升至0.5069，提升了27.14%。这一结果充分证明了多模态记忆建模在视觉导向推荐中的巨大价值。

进一步的消融实验表明，移除属性引导机制（w/o Attr.）或反思机制会导致性能下降。而单独使用推理轨道（MMEACR-DES）或匹配轨道（MMEACR-EMB）虽然也取得了竞争性结果，但融合后的MMEACR-RRF始终更优，验证了双轨设计的互补性。

五、效率与可解释性

除了性能优势，MMEACR在推理效率上同样表现出色。与代表性的AgentCF方法相比，MMEACR在三个数据集上分别实现了6.15%、16.27%和15.11%的推理时间缩减。这一结果表明，结构化属性引导的记忆更新反而比自由格式的语义积累更高效。

在可解释性方面，定性分析显示，传统方法如AgentCF在第五轮交互后已经出现偏好漂移，生成泛化的兴趣总结（如“喜欢爵士”或“喜欢手机配件”）。而MMEACR能够精准捕捉如“强调协调放松氛围”或“重型防护配时尚设计”这样的细粒度偏好，这得益于属性引导的反思机制对语义噪声的有效过滤。

六、展望

MMEACR提出了一种新颖的双轨记忆架构，通过分离智能体推理与密集匹配，成功克服了传统LLM推荐系统在视觉信息和记忆更新方面的局限性。该方法在多个领域的实际数据集上证明了其优越性，尤其是视觉密集型场景中的显著提升。

未来，研究者可以考虑将该框架扩展到视频、音频等多模态内容推荐，同时优化记忆容量与终身学习效率之间的平衡。可以预见，这种融合结构化推理与密集表示的方法，将为下一代推荐系统指明新的技术方向。
