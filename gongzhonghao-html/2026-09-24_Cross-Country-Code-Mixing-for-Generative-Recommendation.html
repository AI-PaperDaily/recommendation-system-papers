Cross-Country Code-Mixing for Generative Recommendation

📅 2026-09-28

阿里国际发布CMRec：代码混合驱动跨境生成式推荐，广告收入提升1.77%

跨境电商平台通常为每个国家独立部署推荐系统，用户与物品ID空间互不相通。这种「数据孤岛」格局意味着，大市场的丰富交互信号天然无法惠及数据稀疏的小市场。尽管生成式推荐（GR）通过将物品映射到共享语义Token空间实现了参数级的知识共享，但训练序列仍严格按国家切分，跨国家的数据级监督信号完全缺失。来自阿里国际数字商业集团的研究团队在CIKM 2026发表的论文中提出了CMRec框架，创新性地借鉴多语言NLP中的语码混合思想，在数据层面合成跨国家混合序列，在线A/B测试中实现了+1.77%广告收入与+2.64%订单量的显著提升。

一、核心方法：从语码混合到跨境推荐

CMRec框架由三个核心组件构成：行为与内容双驱动的共享语义码本、双重约束的跨国家码混合机制、以及上下文感知的自适应重加权损失。整体流程覆盖了从物品表征、序列合成到训练优化的完整链条。

1.1 共享语义码本：让跨国家物品可比

跨国家GR的核心前提是构建一个统一的语义空间。论文采用了双信号驱动策略：首先利用预训练多模态模型将物品的标题、图像等内容信息编码为64维嵌入向量，确保所有国家物品在内容层面可直接比较。然而，仅靠内容相似度远不足以刻画物品在真实市场中的角色——外观相似的商品在不同国家的流行度和共现模式可能天差地别。

为此，论文联合训练了一个跨国的行为驱动i2i对齐模型，采用双塔架构与采样softmax，其训练目标为：

$$\mathcal{L}_{\text{i2i}}=-\sum_{i}\log\frac{\exp(\mathbf{u}_{i}^{\top}\mathbf{e}_{i^{+}})}{\exp(\mathbf{u}_{i}^{\top}\mathbf{e}_{i^{+}})+\sum_{j\in\mathcal{N}_{i}}\exp(\mathbf{u}_{i}^{\top}\mathbf{e}_{j})}$$

其中负样本池$\mathcal{N}_{i}$在全部国家间共享，这使得行为上相似的物品在嵌入空间中彼此靠近。最终，论文使用残差量化器RQ-VAE将融合嵌入转化为长度为$M{=}4$的离散Token序列，形成统一码本。这一码本同时承担两个角色：作为GR模型的Tokenizer，以及作为跨国家Token替换的共同语义底座。

1.2 双重约束码混合：静态与动态信号协同过滤

有了共享码本，理论上可以基于Token表示直接进行跨国家物品替换。但论文指出，码本更新频率较低，无法捕捉价格折扣、流行度、受众标签等快速变化的动态属性。因此，CMRec引入了双重约束的候选集构建策略。

对于物品$i$，其跨国家候选邻居严格限定为同时满足两个条件的物品：Token序列的汉明距离不超过阈值$\tau$，且动态侧信息嵌入的余弦相似度不低于阈值$\tau_s$：

$$\hat{\mathcal{N}}_{\tau,\tau_{s}}(i)=\Big\{j\in\!\!\bigcup_{c^{\prime}\neq c}\!\!\mathcal{I}^{(c^{\prime})}\,\Big|\,d(\mathbf{q}_{i},\mathbf{q}_{j})\leq\tau\;\land\;\mathrm{sim}(\mathbf{s}_{i},\mathbf{s}_{j})\geq\tau_{s}\Big\}$$

其中动态侧信息$\mathbf{s}_{i}$的每个维度按国家进行分位数桶化处理，使不同市场的价格、受众等属性值落入可比较的尺度。这一设计同时在静态内容层面和动态市场层面保证了替换的合理性，有效弥补了单纯内容匹配的不足。训练时，对比例为$p$的样本执行替换操作，每个序列中$k$比例的Token被替换为跨国家邻居。

1.3 上下文感知重加权：让模型自己判断替换质量

即便通过了双重约束过滤，某些替换在特定用户上下文中仍可能不合时宜——例如在一个以苹果设备为主的行为序列中，将某个物品替换为外观相似但生态不兼容的安卓设备。论文为此设计了上下文感知的自适应重加权机制，让GR模型在训练过程中自主评估替换的合理性。

对于从原始样本$(\mathbf{x}, y)$派生的混合样本$(\mathbf{x}^{\prime}, y^{\prime})$，定义上下文条件可替代性权重为：

$$w(y,y^{\prime}\mid\mathbf{x})=\mathrm{sg}\!\left[\frac{P_{\theta}(y^{\prime}\mid\mathbf{x})}{P_{\theta}(y\mid\mathbf{x})+P_{\theta}(y^{\prime}\mid\mathbf{x})}\right]\in[0,1]$$

该权重使用stop-gradient操作确保其不参与梯度更新，仅作为损失中的缩放因子。值得注意的是，替换目标$y^{\prime}$在原始上下文$\mathbf{x}$而非混合上下文$\mathbf{x}^{\prime}$下进行评分——因为模型对观察到的原始序列预测更加可信，这样避免了训练初期合成样本分布外特性导致的评分偏差。最终训练目标为：

$$\mathcal{L}(\theta)=-\sum_{(\mathbf{x},y)\in\mathcal{D}}\log P_{\theta}(y\mid\mathbf{x})-\lambda\sum_{(\mathbf{x}^{\prime},y^{\prime})\in\mathcal{D}^{\prime}}w(y,y^{\prime}\mid\mathbf{x})\log P_{\theta}(y^{\prime}\mid\mathbf{x}^{\prime})$$

二、实验验证：数据稀疏国家收益最显著

论文在工业广告数据集（6国，超10亿交互，19M用户，25M广告，国家间体量差达10倍）和Amazon M2公开数据集（6个语言区域，高资源区域占比91%）上进行了全面评估。

在工业数据集上，CMRec的Recall@100达到0.3613，NDCG@100达到0.1972，较最强基线GenCDR分别提升+5.27%和+4.28%。更值得关注的是分国家表现：在体量最小的S国，Recall@10提升幅度高达+5.32%，而大市场A国也保持了+1.54%的正向提升。这验证了论文的核心主张——跨国家数据级监督信号对数据稀疏市场的增益最为突出，同时不会损害数据丰富市场的表现。Amazon M2数据集的趋势高度一致：低资源区域FR和ES的Recall@100提升分别达到+5.32%和+4.84%，高资源区域UK为+2.57%，均实现了正向收益。

消融实验揭示了各组件相对贡献：移除Token级距离约束导致Recall@100下降4.59%，是影响最大的单一组件，说明码本邻近性是跨国家行为结构迁移的基石；移除上下文感知重加权和侧信息相似度约束分别导致Recall@100下降2.27%和1.11%，进一步确认了动态约束与自适应过滤的必要性。

超参数敏感性实验显示，在两种GR骨干网络上，所有$(p,k)$组合均优于未增强基线，且默认设置（$p{=}10\%, k{=}10\%$）接近最优，表明方法对超参数选择具有良好的鲁棒性。工业平台10%流量的在线A/B测试中，CMRec在六国聚合指标上实现了+1.77%广告收入和+2.64%订单量的提升，证实了离线收益向生产环境的有效迁移。

三、展望

CMRec的核心价值在于为跨境推荐场景提供了数据级知识迁移的新范式——不依赖任何ID重叠或人工锚定，通过语码混合在Token层面构建跨国家监督信号。这一思路对多市场、多区域运营的电商与内容平台具有直接的借鉴意义。在数据隐私约束日益严格的背景下，合成序列替代原始数据交换的路径也展现出独特优势。然而，该方法对共享码本质量的依赖也提示了一个开放问题：当各国物品的内容与行为分布差异过大时，单一码本的表达能力是否依然充足。
