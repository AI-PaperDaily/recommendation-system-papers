Real-Time Hard Negative Sampling via LLM-based Clustering for Large-Scale Two-Tower Retrieval

📅 2026-07-04

Meta发布颠覆性负采样技术：CTR暴涨53%，LLM聚类助力万亿级推荐系统去偏

在推荐系统领域，负样本的质量直接决定了模型的上限。传统方法中，无论是in-batch采样还是随机out-of-batch采样，都面临一个核心困境：生成的负样本太“容易”，模型学不到真正的区分能力。研究者发现，当负样本与正样本差异过大时，梯度更新几乎为零，训练沦为无效过程。

近日，Meta研究团队发表了一项突破性工作，提出基于LLM聚类的实时困难负采样框架Cluster GOOBS，在工业级A/B测试中实现了CTR提升53%的惊人效果，并将Top 100热门物品的展示占比从50%降至32%，显著缓解了推荐系统的流行度偏差问题。该成果已被部署至Meta的亿级用户生产环境。

一、核心方法：Cluster GOOBS实时困难负采样框架

1.1 传统负采样为何失效？

常规的两塔检索模型采用极多类分类公式：

$$P(y_i|x_i;\theta)=\frac{e^{s(x_i,y_i|\theta)}}{\sum_{j\in\mathcal{I}}e^{s(x_i,y_j|\theta)}}$$

其中$\mathcal{I}$是候选物品集合，$s(x_i,y_i|\theta)$是用户和物品的相似度函数。当负样本$y_j$与正样本$y_i$差异过大时，$e^{s(x_i,y_j|\theta)}$趋近于0，梯度信号消失，模型无法学习到微妙的语义区分。

1.2 自监督聚类负采样

论文提出的核心创新在于：强制从同一语义簇中采样负样本。具体而言，对于每个正样本$y_i$，从与其相同簇中采样$K$个负样本$\{y_{i1}^{-n},y_{i2}^{-n},...,y_{iK}^{-n}\}$。损失函数变为：

$$\mathcal{L}=-r_i\cdot\log\left(\frac{e^{s(x_i,y_i|\theta)}}{\sum_{j\in\{y_i,\{y_{ik}^{-n}\}_{k=1}^K\}}e^{s(x_i,y_j|\theta)}}\right)$$

这一设计的理论依据在于：簇内物品共享潜在特征，初始阶段相似度$s(x_i,y_j^{-n})$较高，产生的梯度幅度显著增大，迫使模型学习细粒度的簇内区分。

1.3 LLM驱动的高质量聚类

传统方法依赖物品类别或标签进行聚类，粒度粗糙且难以捕捉深层次语义。论文提出构建基于LLM的多模态内容编码器，通过预训练、多模态编码、微调三步生成语义丰富的嵌入表示，划分出300个高质量语义簇，其中98%的簇包含超过1万物品。

1.4 GOOBS实时采样框架

GOOBS框架的核心在于更新引擎和采样引擎的双向协作。更新引擎通过自定义哈希函数，将每个训练批次中的物品ID映射到对应的簇段槽位。

采样引擎接收当前批次物品的簇ID后，从对应簇段中随机抽取一个已有物品作为OOB负样本。通过预加载历史数据，系统确保了训练初期的采样命中率，同时利用实时更新保持物品池的新鲜度。

二、实验验证：53% CTR提升与去偏奇迹

2.1 公开数据集表现

论文在MovieLens-1M和Amazon Reviews四个子集上进行了严格评估，采用全全局排序而非采样评估，实验条件更为严苛。

数据集 指标 Baseline DNS CBNS ANCE GOOBS Cluster GOOBS
Movielens-1M HR@50 .2253 .2298 .2331 .2380 .2346 .2415
Amazon-Electronics HR@50 .0084 .0090 .0099 .0108 .0110 .0131
Amazon-Home HR@50 .0050 .0054 .0061 .0065 .0067 .0074

Cluster GOOBS在所有指标上全面领先，在Amazon-Electronics上HR@50提升高达55.6%，远超ANCE等几何困难负采样方法，验证了语义簇信息的有效性。

2.2 工业级在线A/B测试

在Meta实际推荐系统中，测试组采用Cluster GOOBS，对照组为普通GOOBS，各覆盖3%用户流量。

模型 CTR提升 训练QPS变化
GOOBS (control) 0% 0%
Cluster GOOBS (test) +53% -1.4%

在线测试显示CTR提升53%，而训练性能仅下降1.4%，推理性能完全不受影响。

模型 ≥1K展示物品占比变化 Top100物品展示占比
GOOBS (control) 0% 50%
Cluster GOOBS (test) +50% 32%

更令人振奋的是，Cluster GOOBS将Top 100热门物品的展示占比从50%降至32%，同时大幅增加了长尾物品的曝光机会。这一效果源于困难负采样打破了“热门物品→更多曝光→更热”的反馈闭环——当模型被迫从同类物品中区分时，长尾物品获得了与热门物品公平竞技的机会。

三、未来展望

Cluster GOOBS为大规模推荐系统提供了一种优雅而高效的负采样方案。论文指出，未来方向包括加权簇负采样（根据不同簇的区分难度赋予不同采样权重）以及基于用户查询的动态负采样。

对于正在构建推荐系统的工程师而言，这一工作的启示在于：真正的困难负样本并非来自随机或全局最近邻，而来自同一语义簇内的细致区分。这或许是打破推荐系统“信息茧房”的一把关键钥匙。
